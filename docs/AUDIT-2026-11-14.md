## 2. 玩法、目标与操作

**目标**：俯视角双摇杆生存射击，无尽波次守住黄昏农场。被击倒即结算（存活波次 / 击杀 / 总分 / 命中率 / 时间 / 金币 / 历史最佳）。0 分不写纪录；正常 / `?bot` / `?fragile` 三档分存。

**胜利节奏**：无最终关；第 5、10、15… 波出现鸭王 Boss。成长靠击杀/清波经验 → 天赋点（T）与金币商店（B）。

| 输入 | 动作 |
| --- | --- |
| WASD / 左摇杆 | 移动 |
| 鼠标 / 右摇杆 | 瞄准。准星钉在指针（方向指示）；真实落点看地面琥珀环 |
| 左键 / RT·LT | 射击 |
| R / X | 换弹（空匣开火会自动换弹） |
| 空格 / A | 冲刺（约 0.22s，无敌 0.34s，冷却 1.1s，天赋可缩短） |
| B / 手柄 B | 商店（战斗暂停） |
| T / Y | 天赋树（战斗暂停） |
| 1–4 | 主动技能（需天赋解锁） |
| Q / E / 滚轮 / LB·RB | 战斗中切枪 |
| Esc / P / Start | 暂停（音量滑条 + M 静音，localStorage 持久化） |
| Enter | 标题开局；**结算后再次守卫**（本轮补上） |
| Esc | 结算后回标题（本轮补上） |
| F3 | 性能叠加层 |

手柄与键鼠共存。商店 / 天赋 / 暂停支持摇杆·十字键导航 + A 确认 + B 返回。

- 前次提交已做鸭子几何/材质全局缓存、输入状态清理、手柄共存、纪录分档，方向正确。

### 3.5 可玩性

**数值事实（代码算出，作经济/难度基线）**

- 第 1 波：6 空手 + 1 精英，约 72 金币、97 经验（含清波 25，精英按跑者/灰鸭溢价）。鞋子 150、手套 120，**第一波几乎买不起护具**；子弹箱 60 勉强。
- 第 1–4 波击杀金币下界（不含精英溢价）≥ 连发枪 320，且 < 重步枪+霰弹之和。单测已锁。「第一把付费枪」窗口约在第 3–4 波。
- 第 5 波起有 Boss + 重装；第 7 波起总量锁 42，之后主要靠 hpScale / speedScale / 兵种配比变化。第 16 波起杂兵保底 2。
- 经验曲线 `30+(L-1)*18`；12 节点满级共 23 点。前期升级快（第 1 波即可 1–2 级）。
- Boss「暴君嘎」全图、1.6s 蓄力、9s 冷却；冲刺无敌仅 0.34s、冷却 1.1s，**必须看预警闪**。精英践踏半径 4.5、前摇 0.9s。
- README 写明精英/Boss「蓄力时原地顿足」；代码原先 `want*0.15` 仍会位移，预警圈与伤害圆心可能错位。**本轮已改为蓄力锁位，践踏按 `skillPos` 结算**。
- 弹药双保险：击杀低弹必掉 + 空弹 6s 脚边紧急补给（每波一次）。
- `spreadNow` 的移动/过热散布用的是全局 `WEAPON`（卡宾）常数，只有 `spreadBase` 按枪。手感可能让霰弹/重步枪「走路散布」同质。**改数值需试玩，本轮不动**。

**重大取舍（只推荐，不在本轮改）**

1. **商店暂停战斗**：休闲向，保留。不要改成实时商店，除非试玩强烈抱怨节奏被打断或被当成「暂停键滥用」。
2. **不要先重做经济/枪价/波次公式**。先记录：第一把付费枪出现波次、第 5 波前死亡率、第 7 波后是否单调。若「前期穷得无聊」再下调连发枪价或提高前 3 波金币，而不是全面膨胀。
3. **Boss 全图冲击波**保留为关卡技能检查；若试玩觉得无法阅读或窗口过苛，优先加长前摇或给地面脉冲更强，而不是删技能。
4. **不要新开地图/新枪线/新模式** 来凑内容；先把现有一关的节奏、可读性、画质档做实。
5. **不要拆分重写 `game.js`**，除非某次功能改动已天然切出模块。

## 6. 真实试玩协议（给后续浏览器试玩）

服务：http://127.0.0.1:5173/  （同机器访问；不要假定已从外网可达）

建议局次（均开 F3，结束截图）：

1. **首局引导**：默认打开标题 → 读说明 → 极致画质 → Enter 开局。记录标题闲置 FPS。打到第 3 波或第一次死亡。检查准星是否钉在鼠标、落点环是否只在偏差时出现、商店卡宾、T 天赋、Esc 暂停与音量滑条。
2. **经济与成长**：不刻意刷，记录第一次买到付费枪的波次与金币、第一次升级、第一次解锁主动技能。
3. **精英与 Boss**：至少经历一次精英践踏（圈与伤害是否一致、能否出圈）和第 5 波鸭王冲击波（预警横幅是否被覆盖、冲刺窗口是否可读）。
4. **均衡画质**：刷新后先点「均衡」再开局。第二轮已让世界草量/阴影与 Bloom 跟随按钮（软件渲染除外）。试玩时对比 F3 的 FPS / tris / 草密度，确认切回「极致」草会恢复。
5. **结算与重开**：死亡后先等结算，Enter 再开；再死一次 Esc 回标题。连开 5 局看 F3 geos/tex 是否稳定。
6. **压力**：若能存活，打到第 7 波（42 敌人）记 FPS。可用 `?bot` 作自动演示对照，但玩家手感以键鼠局为准。
7. **负面用例**：滚轮误切枪、切标签暂停、空弹耗尽等紧急补给、朝天瞄准、隔干草垛近战、池塘落弹无焦痕。

记录请写：操作、期望、实际、截图路径、F3 数字、波次、是否阻塞。不要在试玩反馈前把主观「好不好玩」写成已落地的改动。
