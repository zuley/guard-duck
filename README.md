# 守卫鸭鸭

一只愤怒的卡通鸭子，守住它的农场。俯视角双摇杆生存射击，单迷你关卡、无尽波次。
美术风格参考《逃离鸭科夫》：程序化生成的 PBR 材质、动态天空与水面、风动植被、
胶片级后处理——全部资源由代码生成，无任何外部图片/模型/音频文件。

## 运行

```bash
npm install          # 网络受限时可用: npm install --registry=https://mirrors.cloud.tencent.com/npm/
npm run dev          # http://127.0.0.1:5173
npm run build        # 产出 dist/
npm test             # Vitest 数值规则单测（86 项）
node scripts/e2e.mjs # 无头 Chrome 真实键鼠端到端（96 项，含截图）
node scripts/playtest.mjs # 测评修复验证（21 项：输入/手柄/弹药/纪录/资源等回归）
```

需要支持 WebGL2 的浏览器。软件渲染环境（SwiftShader 等）会自动降档保证可玩。

## 玩法

- 波次生存，敌人武器逐波递进：第 1 波需求鸭（空手）→ 第 2 波混入 BUG鸭（棍棒）/ 产品鸭（小刀）近战 →
  第 3 波混入前端鸭（手枪）→ 第 4 波混入后端鸭（步枪）→ 第 5 波起设计鸭（霰弹）登场、全员齐备、强度递增、单波总量封顶 42（含精英与 Boss）。
  敌人名字带打工人风味：任务 / 职位鸭约六成概率随机带前缀（紧急需求鸭、生产 BUG鸭、愤怒的产品鸭、实习的后端鸭…），
  名字在出生时确定，头顶血条上方、击杀播报与精英来袭提示保持一致。
  近战挥击有举武器前摇，可后撤或冲刺闪避，**掩体能挡住挥击视线**；远程敌人进入视野才开火；敌人会互相挤开、不叠影。
  杂兵数量随波次平滑递减，兵种构成逐波升级。
- **每波 1 名精英**：当波兵种随机强化，体型 ×1.45、红莫西干、琥珀血条，血量 / 伤害加强，
  分值 / 金币 / 经验 ×3，必掉补给箱 + 2 份鸭杂。技能「战争践踏」：0.9 秒预警圈（半径 4.5）后
  对圈内玩家造成伤害，蓄力时原地顿足，应对是快出圈。
- **每 5 波领导 Boss**：戴金冠的巨型霰弹鸭，名字随机取自各路领导（产品Leader、研发主管、项目经理、技术总监…），
  血量走独立成长曲线（不随普通波封顶而停滞），击杀缴获大量鸭杂与金币。技能「暴君嘎」：每 9 秒一次全图冲击波，
  1.6 秒蓄力（**独立高优先级预警横幅** + 全图红色预警圈，不会被技能 / 拾取提示覆盖），释放时无视距离命中，用冲刺无敌帧看准时机闪避。
- **头顶血条**：所有敌人（红）与玩家（绿）头顶常驻血条，随血量实时缩短；玩家阵亡后隐藏。
  玩家换弹时血条下方附加琥珀色换弹进度条，换弹完成即隐藏。
- 出怪门在屏幕外时，屏幕边缘弹出红色箭头预警指向来袭方向；HUD 实时显示剩余敌人计数。
- 击杀掉落弹药箱 / 面包（回血）；**弹匣 + 备弹低于 30 时击杀必掉弹药箱**；
  备弹彻底打空（无法击杀 → 无掉落）时 **6 秒后脚边自动紧急补给一个弹药箱**（每波一次），双保险杜绝弹药死锁；
  备弹为全部枪支通用。脱战 6 秒后缓慢回血。
- 击杀获得金币（按敌人分值折算）；敌人还会掉落鸭杂战利品，拾取入背包。
- **准星只指示方向**：准星始终钉在鼠标指针处（手柄瞄准时取虚拟瞄准点投影），不吸附、不跳动。
  内部瞄准仍取敌人包围球表面 / 地面，再沿弹道以与子弹完全相同的判定（敌人半径 / 掩体 / 地面）
  步进预测首个命中点；**真实落点由地面琥珀色圆环单独标出**（与准星分离超过 0.5m 时显示），
  配合曳光与弹着贴花，空地指哪打哪、被敌人或干草垛遮挡时落点环提前停在遮挡物上。
- 伤害按**每把枪独立的距离衰减曲线**计算：霰弹枪近距爆发（6 弹丸 × 15，远距急剧衰减），
  重步枪远距保持伤害；命中率按弹丸计，霰弹一枪计 6 发。
- **最高分持久化**（localStorage）：阵亡结算存活波次 / 击杀 / 总分 / 命中率 / 存活时间 /
  金币收入 / 历史最佳，刷新或追平纪录显示「新纪录！」徽章；0 分不写纪录，
  正常 / `?bot` 演示 / `?fragile` 挑战三种模式分档存储互不污染。阵亡结算延迟期内按任意键可跳过。
- **等级成长**：击杀与整波肃清获得经验，升级回复 30% 生命并获得 1 天赋点；
  HUD左上显示等级徽章 / 经验条 / 天赋点。天赋点投入天赋树换取被动强化与技能强化。
- **技能随等级解锁**：开局自带「嘎嘎乱杀」(键1)，之后每升 3 级解锁一个新技能
  （Lv.3 抱头蹲防 → Lv.6 红温暴走 → Lv.9 嘎瓦鲁多），Lv.9 四技能齐。
  未解锁的技能格灰显并标注所需等级；解锁瞬间弹提示 + 升级音效。

## 等级与天赋（T 键）

打开天赋树时战斗完全暂停。三条分支 × 四层共 12 节点，逐层解锁（上一层至少 1 点），
每点 1 天赋点。★ 节点强化对应主动技能（技能本身按等级解锁，见上）：

- **火力**（红）：嘴强王者（子弹伤害 +8%/点）→ ★乱杀强化（嘎嘎乱杀伤害/半径）→
  杀疯了（伤害/半径再强化）→ ★红温强化（红温暴走持续 +2s · 伤害再 +10%）。
- **守护**（绿）：贴秋膘（生命上限 +20/点）→ ★蹲防强化（抱头蹲防护盾 +30 · 持续 +1s）→
  加厚羽绒（护盾值/持续再强化）→ 吃鸭补鸭（击杀回血 +4/点）。
- **迅捷**（蓝）：冲鸭（移速 +6%/点）→ ★时停强化（嘎瓦鲁多持续 +1s · 敌人更慢）→
  时停续杯（持续/减速幅度再强化）→ 溜了溜了（冲刺冷却 -20%/点）。

四个主动技能（键 1-4，各有独立冷却）：嘎嘎乱杀（范围伤害+击退）、抱头蹲防（吸收护盾）、
红温暴走（短时射速 +45% · 伤害 +35%）、嘎瓦鲁多（全场敌人减速）。
底部技能栏实时显示四格：未解锁灰显 + 所需等级、冷却遮罩 + 倒计时、生效中高亮描边。
天赋与护具加成叠乘合成（`applyTalents`），换弹 / 移速 / 生命上限即时生效。

## 农场商店（B 键）

打开商店时战斗完全暂停。两个页签均为**图标格子**（程序化 canvas 图标 + 价格 / 数量 / 等级 / 状态角标），
鼠标移入弹出浮层展示名称 / 类别 / 数值 / 价格 / 操作提示，移开即隐藏；点击格子执行购买 / 升级 / 装备 / 卖 1。两个页签：

- **购买装备**：4 种枪支（「牧群」连发枪 / 「干草」霰弹枪 / 「守夜」重步枪，
  初始「谷仓」卡宾枪免费，可用 Q/E·滚轮 切换）、子弹箱（备弹 +48）。
  护具均为**三阶升级**，重复购买即升阶、金币持续回收：
  盔甲（受伤 -30/-45/-60%）、头盔（生命上限 +30/+60/+100）、
  鞋子（移速 +15/+25/+35%）、手套（换弹 -30/-45/-60% · 散布 -25/-40/-50%）。
  已购枪支可随时切换，各枪弹匣独立保存；护具购买后鸭鸭身上直接显示对应模型。
- **出售背包**：鸭头 / 鸭脖 / 鸭翅 / 鸭掌 / 鸭锁骨 / 鸭毛 / 鸭血 / 鸭肠 / 鸭胗 / 鸭肝 / 鸭食管，
  共 11 种鸭杂，按稀有度加权掉落，可单卖或全卖换金币。

## 技术要点

- **渲染**：Three.js r180，ACES 色调映射 + PCF 软阴影 + PMREM 环境光；
  后处理链 Bloom → 自定义调色（暗角 / 颗粒 / 色散 / 分离色调）→ FXAA。
- **世界**：程序化 canvas PBR 贴图（草 / 土 / 木 / 金属 / 干草）+ 高度图转法线；
  地形 splat 混合、GLSL 天空（太阳 / 云 / 星）与水面（菲涅尔 / 岸边泡沫）；
  实例化风动草叶与芦苇、树冠摇曳、萤火虫 / 尘埃 / 飞鸟、灯柱火苗闪烁。
- **角色**：参照图还原的卡通鸭（三瓣呆毛、怒眉、橙色大嘴），程序化走路 / 眨眼 /
  后坐 / 换弹（枪口下压、弹匣落下插入、左翅前伸、低头）/ 冲刺 / 死亡动画，菲涅尔轮廓光；敌人同款换装配饰（头巾 / 绷带 / 钢盔），
  领导 Boss 体型 ×2、戴金冠；精英体型 ×1.45、红莫西干；敌我全员头顶血条 + 名字（敌红我绿精英琥珀）。
- **战斗反馈**：弹壳抛掷物理、可见弹体 + 随动短拖尾、小幅枪口闪光 + 动态光池（光强随火光缩放）、
  羽毛 / 烟雾实例化 billboard、火花、贴花、伤害数字、命中准星反馈、屏幕震动、
  精英 / Boss 技能地面预警圈（脉冲描边 + 半透明圆盘）与释放冲击波。
- **音频**：WebAudio 全合成音效（枪声 / 鸭叫 / 换弹 / 拾取 / 波次号角 / 技能释放 / 升级 / 技能爆炸）+
  环境声床 + 程序化 BGM（四和弦循环垫底 + 琶音，开局自动播放、阵亡 / 回标题淡出）。
  暂停菜单音量滑条 + M 键静音，音量持久化；换弹音效节点按实际换弹时长等比排程（手套缩短换弹不再「换完还响」）。
- **数值**：`src/rules.js` 纯函数（波次规划 / Boss 独立成长曲线 / 每枪距离衰减 / 散布 /
  低弹药掉落兜底 / 金币 / 鸭杂 / 护具三阶加成 / 经验曲线 / 天赋树 / 技能表 / 加成合成 /
  射线取球面与弹道落点步进），86 项单测覆盖。
- **资源管理**：鸭子几何体 / 材质全局缓存共享，刷怪 / 切枪 / 重开不再累积 GPU 资源；
  每只鸭独立的阴影材质随移除释放。输入状态在暂停 / 开关菜单 / 重开时统一清理，
  切窗、商店空格购买、手柄接入均不会残留成自动走火 / 冲刺。
