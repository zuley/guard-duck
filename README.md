# 守卫鸭鸭

一只愤怒的卡通鸭子，守住它的农场。俯视角双摇杆生存射击，单迷你关卡、无尽波次。
美术风格参考《逃离鸭科夫》：程序化生成的 PBR 材质、动态天空与水面、风动植被、
胶片级后处理——全部资源由代码生成，无任何外部图片/模型/音频文件。

**五家 AI 计划只是本地游戏主题**：用游戏刀按波订阅，用游戏 Token 发动武器攻击。
不调用真实模型 API，不接入真实账号或支付，不生成或收集真实手机号、信用卡、IP 或 KYC 资料。
套餐、额度、战斗属性、封号概率与保护道具都是虚构平衡设计，不是官方产品承诺或真实平台风控统计；
也不表示任何真实聊天会员包含 API 额度。

## 运行

```bash
npm install          # 网络受限时可用: npm install --registry=https://mirrors.cloud.tencent.com/npm/
npm run dev          # http://127.0.0.1:5173
npm run build        # 产出 dist/
npm test             # Vitest 规则 / 订阅账本 / 拾取资源单测
node scripts/e2e.mjs # 无头 Chrome 真实键鼠端到端（含截图）
node scripts/playtest.mjs # 输入 / 手柄 / 订阅与 Token / 纪录 / 资源回归验证
node scripts/cardtest.mjs # 波次强化卡运行时验证（抽卡 / 选卡 / 稀有度 / 特效 / 布局）
```

需要支持 WebGL2 的浏览器。软件渲染环境（SwiftShader 等）会自动降档保证可玩。

## 单一订阅与 Token 经济（B 键）

开局有 **180 刀启动预算**，不计入累计收入（刀）。游戏先冻结在五计划选择面板，默认聚焦 DS，
但必须由玩家确认一项并立即支付首波费用才进入战斗；未选择时 Esc 返回标题。
按 `B`（手柄 B）打开后战斗时间冻结；首次确认会关闭面板，之后付费切换仍留在面板内，方便比较。
只同时维持一个计划，没有永久购入、免费装备或战斗快捷切换列表。

下表费用、额度与调用成本均为**游戏参数**，没有真实扣款；无卡牌加成时：

| 计划 / ID | 每波刀 | 每波 Token | 超额刀 / 千 Token | 全额度可付完整调用 | 纯按量一次调用 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Claude / `claude` | 150 | 1,250 | 160 | 19 次，余 34 Token | 10.24 刀 |
| GPT / `gpt` | 120 | 2,000 | 80 | 62 次，余 16 Token | 2.56 刀 |
| Qwen / `qwen` | 45 | 1,200 | 50 | 37 次，余 16 Token | 1.6 刀 |
| GLM / `glm` | 44 | 1,600 | 36.5 | 50 次 | 1.168 刀 |
| DS / `ds` | 15 | 2,000 | 9.75 | 181 次，余 9 Token | 0.10725 刀 |

- **按波续订与额度到期**：进入新波次时尝试扣整笔订阅费、刷新额度；旧额度到期作废，不跨波叠加。
  初次付款覆盖第 1 波，第 1 波真正开始时不会再收费或重复发额度。同一波只处理一次续订。
- **立即全费切换**：只在面板明确确认目标计划时扣目标的完整每波费用，丢弃旧额度并发放目标额度；
  切回以前用过的计划也要付费，不退还旧计划费用。点击当前计划不收费、不补额度。
  余额不足则整笔拒绝，保留原计划与资源。
- **波间预付**：波间切换算预付下一波，额度立即可用；下一波开始时既不重复收费，也不再次补满。
- **续订失败转按量**：余额不够整笔续费时不扣部分费用、不发新额度，仍保留该模型，状态为「未续费·按量」。
  本波即使后来进账也不反复自动补扣；下波才重新尝试续订，或由玩家主动付费切换。
- **先额度、后刀**：成功武器调用基础消耗 **32 Token**（DS 11、Claude 64），不足的部分按 Token 从刀扣费；
  例如 DS 剩 9 Token 时，下次再付 2 Token 的 0.0195 刀，而非收整次按量费。
  连剩余额度加余额也无法支付整次时，整次攻击失败，不吞部分额度、不生成弹体、不欠债。
- **一次齐射只计一次调用**：GLM 六弹丸、多重射击、穿透、多目标命中、连锁、爆炸等不重复收费。
  命中率仍按实际弹丸统计，调用数与弹丸数不同。主动技能、卡牌触发与冲刺都不额外消耗 Token / 刀，
  主动技能继续使用独立冷却；余额耗尽时仍能移动、用技能战斗和拾取收入。
- **预期经济取舍**：DS 低费长续航，首购后余 165 刀；Claude 首购后余 30 刀，适合用高单发伤害打精英、用范围爆炸清群。
  对应同量按量购买，订阅费约优惠 25%，但按整刀向上取整（GLM 43.8 → 44，DS 14.625 → 15）；
  没用完的额度不退费，高射速也会更快消耗额度。击杀与福利是续费 / 超额支出的主要收入，不能假定每波收入固定或必定回本。

## 虚构封号与保护道具

**这里只是阵亡机制，不触发任何真实封号或身份验证。** 每次成功支付武器调用后才独立抽取一次：
Claude 基础概率 **5% / 次**，GPT **0.05% / 次**，Qwen / GLM / DS 为 0，不抽取封号随机数。
不是按帧、弹丸或命中计数；余额不足、冷却中与暂停时不抽取。
无保护连续调用 200 次，至少一次封号的游戏概率约为 Claude 99.996%、GPT 9.5%。

四种等强度道具只记录名称、图标和层数：**美国手机号**（`us_phone`）、**美国信用卡**（`us_credit`）、
**美国住宅IP**（`us_ip`）、**KYC验证**（`kyc`）。没有填表、真实资料、支付或账号接入。
每层把风险乘 0.8，按四种物品的总层数计算：

```text
实际游戏封号率 = 基础概率 × max(0.05, 0.8 ^ 总层数)
```

最多降低 95%，不能把 Claude / GPT 的风险降至零，也不影响另外三家原本的零风险。
普通 / 精英 / Boss 击杀分别以 **12% / 25% / 60%** 概率独立额外掉落一件，四种等权；
不挤占工资、福利或回血掉落。整局持有、不消耗，跨波与切换保留，重开清零。
封号会直接结束本局，绕过护盾、无敌、守护结界与不死鸟；该次资源已支付但不会生成攻击，结果页标明原因与虚构机制说明。

## 波次、生存与成长

- 敌人逐波递进：第 1 波需求鸭（空手）→ 第 2 波混入 BUG鸭（棍棒）/ 产品鸭（小刀）近战 →
  第 3 波前端鸭（手枪）→ 第 4 波后端鸭（步枪）→ 第 5 波起设计鸭（霰弹）登场；单波总量封顶 42（含精英与 Boss）。
  名字带打工人风味：任务 / 职位鸭约六成随机带前缀（紧急需求鸭、生产 BUG鸭、愤怒的产品鸭、实习的后端鸭…），
  出生后头顶名字、击杀播报与精英提示保持一致。杂兵随波次平滑递减，兵种构成逐波升级。
- 近战挥击有举武器前摇，可后撤或冲刺闪避，**掩体能挡住挥击视线**；远程敌人进入视野才开火，敌人互相挤开、不叠影。
- **每波 1 名精英**：体型 ×1.45、红莫西干、琥珀血条，血量 / 伤害加强，分值 / 刀 / 经验 ×3，福利掉落次数增加。
  「战争践踏」在 0.9 秒预警圈（半径 4.5）后伤害圈内玩家，蓄力时原地顿足，应快速出圈。
- **每 5 波领导 Boss**：戴金冠的巨型霰弹鸭，名字随机取自各路领导（产品Leader、研发主管、项目经理、技术总监…），
  独立血量成长、击杀收益与额外福利。「暴君嘎」每 9 秒发动一次全图冲击波，1.6 秒蓄力，
  **独立高优先级横幅 + 全图红色预警圈**不会被拾取提示覆盖；冲刺无敌帧可闪避战斗伤害，但不能免除游戏封号。
- **头顶血条**：敌红、玩家绿、精英琥珀，阵亡后隐藏；HUD 显示 Token / 按量状态与剩余敌人数，出怪门在屏幕外时有边缘箭头预警。
- 击杀获得刀与经验，福利拾取立即生效；普通补给仅保留面包回血，原资源补给分支为空掉落，不变相提高回血概率，
  没有免费 Token 箱。脱战 6 秒后缓慢回血，升级回复 30% 生命。
- **准星只指示方向**：始终钉在鼠标处（手柄使用虚拟瞄准点），不吸附或跳动；内部沿各武器的弹道预测停止点，GLM 的落点环以扇面中线为准。
  **真实停止点用地面琥珀环单独标出**（与准星分离超过 0.5m 时显示；射程内瞄空地时环落在射程末端），配合命中贴花；伤害按计划各自的距离衰减曲线计算。
  加班炸弹技能仍朝准星鼠标点投掷，不受弹道停止点影响。
  已发弹道保留发射时的属性快照，不被之后的付费切换改写。
- **最高分持久化**（localStorage）：结算存活波次 / 击杀 / 总分 / 命中率 / 存活时间 / 收入（刀） / 历史最佳，
  刷新或追平显示「新纪录！」，0 分不写纪录；正常 / `?bot` / `?fragile` 分档存储。阵亡结算延迟期内按任意键可跳过。
- 等级只负责解锁技能，属性成长来自波次强化卡；左上等级徽章 / 经验条 / 已获卡牌层数实时更新。
  开局「加班」(键 1)，Lv.3 调休、Lv.6 996、Lv.9 卷王模式；未解锁格灰显并标注等级。

## 波次强化卡（每波肃清三选一）

清空一波后战斗完全暂停，弹出 **3 张互不相同的强化卡**，选 1 张立即生效并继续下一波。
`1/2/3` 直选，方向键 / A·D 移动焦点 + 回车，也可点击；手柄导航 + A 确认。
**必须三选一**，Esc / B / Start 不能跳过；选卡期间战斗时间冻结，护卫羽毛继续环绕。

普通 / 稀有 / 传说权重为 **70 / 22 / 8**，普通米白圆角方、稀有绿六边形、传说金星芒；金卡额外流光与呼吸边框。
每张可重复叠层，各有上限，满层退出卡池；某档抽空时降级到其它档，卡池全空则跳过，**每 5 波 Boss 保底一张金卡**。

- **普通 14 张**：尖嘴利喙、贴秋膘、冲鸭、Token 优化、扩展配额、狂热扣扳、溜了溜了、硬羽绒、稳如老鸭、
  自愈绒毛、财迷鸭、好学鸭、加长枪管、预算补贴。
- **稀有 12 张**：爆破弹、穿甲弹、霜冻弹、吸血喙、致命一击、荆棘羽绒、吃鸭补鸭、开工护盾、铁头冲撞、燃烧弹、拾取磁铁、消费返现。
- **传说 10 张**：连锁闪电、护卫羽毛、处决喙、不死鸟、血怒、双管齐下、守护结界、点金术、时停收割、乱杀精通。
  不死鸟 / 守护结界只处理战斗伤害，不抵挡封号死亡。

四张资源卡保留稳定 ID，效果改为本地经济加成：

| ID | 名称 | 每层效果 |
| --- | --- | --- |
| `c_reload` | Token 优化 | 基础 Token 用量 -10% / 层，向上取整，每次至少 1 Token |
| `c_mag` | 扩展配额 | 之后发放的订阅额度 +25% / 层；不追补当前额度，重算属性 / 开关面板不白送额度 |
| `c_ammo` | 预算补贴 | 获得时立即 +30 刀；超额按量单价 -10% / 层，不影响订阅费 |
| `r_ammoBack` | 消费返现 | 击杀有 25% × 层数的概率额外返还 4 刀 |

按 `T`（手柄 Y）打开**卡牌图鉴**：金 → 绿 → 普通排序，显示层数与效果。
属性组合本身不会扣费、重发额度或清空保护道具；重开清空卡牌与特效实体。
四主动技能独立冷却且免费，打工人主题并带经济钩子：

| 技能 | 冷却 | 效果 |
| --- | ---: | --- |
| 加班 | 12s | 扔出加班炸弹，0.6s 后爆炸形成大范围闪电冲击波（基础半径 9）：低伤害 + 定身 3s（头顶显示「加班中」），主打控场；范围内每击杀 1 名敌人额外结算 8 刀加班费 |

## 打工人福利（拾取即生效）

福利按权重掉落，以补贴 / 工资信封、纸质凭证、礼盒、咖啡杯等模型和名称标签区分。
拾取一次性结算收益与效果，不进库存、不需出售，回血不超过生命上限；经验效果应用现有经验倍率。

| 福利 | 刀 | 即时效果 |
| --- | ---: | --- |
| 高温补贴 | 6 | 回复 10 生命 |
| 节日福利 | 10 | 护盾 +20（福利补盾封顶 120） |
| 本月工资 | 14 | 回复 25 生命 |
| 下午茶 | 8 | 移速 +25%，持续 5 秒 |
| 加班费 | 18 | 经验 +12 |
| 季度绩效 | 24 | 经验 +30 |
| 项目奖金 | 32 | 996 4 秒 |
| 年终奖 | 60 | 回复 60 生命 |
| 期权激励 | 88 | 生命回满 |

福利与被动护盾不会因主动防御技能计时结束而清空。击杀收入、福利、回血与保护道具使用各自掉落结算，互不顶替。

## 技术要点

- **渲染**：Three.js r180，ACES + PCF 软阴影 + PMREM；Bloom → 自定义调色（暗角 / 颗粒 / 色散 / 分离色调）→ FXAA。
- **世界**：程序化 canvas PBR 贴图与高度图法线；地形 splat、GLSL 天空 / 水面、实例化风动植被、萤火虫 / 尘埃 / 飞鸟、灯柱火苗。
- **角色与反馈**：程序化走路 / 眨眼 / 后坐 / 冲刺 / 死亡动画；模型主题武器、敌人配饰、领导金冠与精英红莫西干；
  实体圆点弹道 / GPT 激光束（Claude 导弹带尾焰拖尾）、枪口闪光 + 动态光池、羽毛 / 烟雾、火花、贴花、伤害数字、屏幕震动、技能预警圈与冲击波。
- **音频**：WebAudio 全合成枪声 / 鸭叫 / 拾取 / 波次号角 / 技能 / 升级音效、环境声床与程序化 BGM；
  暂停音量滑条 + M 静音，音量持久化，开局音乐自动播放、阵亡 / 回标题淡出。
- **规则与账本**：`src/subscriptions.js` 集中五计划、参考日期 / 来源 / AA 指数、报价公式、微金币、Token 支付、风险与保护道具；
  `src/rules.js` 复用计划表，维护波次、Boss 成长、距离衰减、刀 / 福利、经验 / 卡池 / 技能与属性组合。
  内部 `walletMicros` 是整数微金币，`coins` / `coinsEarned` 接口以刀表达；启动预算不算收入，统计调用数与 Token 用量。
- **生命周期**：幂等 `endRun('combat' | 'ban')` 终止入口，死亡后本帧不继续收入 / 拾取 / 刷波；
  独立 `banRng` 供确定性测试与宣传摆拍，不把战斗无敌误当成封号保护。
- **资源管理**：鸭子几何体 / 材质共享，独立阴影材质随移除释放；`src/pickups.js` 为福利、回血与四种保护物品维护有限模板缓存，
  重复掉落共享几何体 / 材质 / 标签纹理。暂停 / 菜单 / 重开清输入，浏览器脚本检查生命周期与窄屏布局。
